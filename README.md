# NIS-GameCenter — учебная мастерская 2D-игр

Рабочий прототип браузерного редактора для занятий с 7 классом. Русский интерфейс, программирование на JavaScript, знакомая по Unity компонентная модель. Никаких внешних зависимостей, CDN и регистрации. Интернет для работы не требуется.

## Запуск

**Windows:** дважды нажмите `start.cmd`, затем откройте <http://localhost:5173>.

Нужен Node.js 18+ **или** Python 3. При установленном Node.js:

```sh
node tools/server.mjs
```

Альтернатива с Python:

```sh
python -m http.server 5173 --bind 127.0.0.1
```

Не открывайте `index.html` через `file://`: ES-модули и Worker требуют HTTP. Для школьной локальной сети можно раздать статические файлы любым HTTP-сервером. Например, `python -m http.server 5173 --bind 0.0.0.0`, затем открыть `http://IP-компьютера-учителя:5173` с ученических компьютеров. Доступ к порту должен быть разрешён настройками школьной сети. Локальный скрипт `start.cmd` по умолчанию доступен только на текущем компьютере.

## Возможности

- Сцена: выбор, перетаскивание, привязка к сетке, масштабирование и перемещение вида.
- Список объектов: поиск, включение/отключение, создание, дублирование и удаление.
- Инспектор: Transform, SpriteRenderer, Rigidbody2D, Box/CircleCollider2D, Script, Camera2D.
- Физика: гравитация, динамические и статические тела, повёрнутые прямоугольники и окружности, масса, трение, отскок и триггеры.
- Код: редактор с подсветкой, номерами строк, консолью и сообщениями об ошибках.
- Скрипты: `start`, `update`, `fixedUpdate`, события входа/выхода столкновений и триггеров; Input, Scene, Debug.
- Запуск, остановка, пауза, один шаг. Изменения игрового состояния не затрагивают исходный проект.
- Скрипты и физика выполняются в Worker. Зависший поток завершается примерно через 2.5 секунды, редактор остаётся доступным.
- Undo/redo, автосохранение в localStorage, перенос проекта одним JSON-файлом вместе с изображениями и кодом.
- Встроенные спрайты, загрузка PNG/JPEG/WebP, готовый платформер и десять уроков.
- Камера: масштаб, цвет фона и слежение за объектом.

Откройте «Справка» внутри редактора для полного описания API. В платформере соберите три монетки и доберитесь до флага. Движение: стрелки или A/D, прыжок: пробел.

## Учебный курс: 10 занятий по 45 минут

Кнопка «Учебник» открывает полную программу с навигацией по всем урокам. Каждый урок содержит цели, объяснение понятий, пошаговую практику, проверяемое задание, критерии результата, вопросы с раскрывающимися ответами, дополнительную и домашнюю работу. В уроках по программированию есть полные примеры JavaScript с инструкцией по подключению и кнопкой копирования.

| Урок | Тема | Результат |
| --- | --- | --- |
| 1 | Знакомство со сценой | Положение объектов, запуск и сохранение проекта |
| 2 | Гравитация и столкновения | Физическая площадка, Rigidbody и Collider |
| 3 | Первая строчка кода | Управление, прыжок и сообщение в консоли |
| 4 | Монетки и события | Триггеры, счёт и условие победы |
| 5 | Собственный уровень | Проходимый маршрут и тестирование в парах |
| 6 | Переменные и функции | Настройки персонажа и метод возвращения на старт |
| 7 | Движущиеся препятствия | Патруль, время dt и опасный триггер |
| 8 | Графика и камера | Свои изображения, слои и слежение за игроком |
| 9 | Отладка и тестирование | Консоль, тест-план и исправление ошибки |
| 10 | Итоговый проект и защита | Законченная мини-игра с объяснением своего кода |

В каждом уроке есть собственная наглядная SVG-иллюстрация, три короткие карточки с раскрываемыми объяснениями, вопрос «Предскажи результат» с обратной связью и визуальная цепочка действий. Картинку можно открыть крупнее. Все изображения локальные: интернет и внешние CDN не нужны.

Урок можно распечатать. В навигации учебника доступны текстовая Markdown-версия и автономный HTML-курс с картинками внутри файла. Пройденные уроки и последний открытый урок сохраняются в проекте, включая экспорт в JSON. Название сайта изменено на NIS-GameCenter; старые проекты и автосохранение «Кадра» по-прежнему открываются. Нумерация первых пяти тем сохранена для совместимости с предыдущим прогрессом.

## Проверки и сборка

```sh
node --test
node tools/build.mjs
node tools/server.mjs dist
```

Сборка копирует приложение в `dist/`, подходящий для статического хостинга, и создаёт `dist/materials/10-lessons.md` со всеми материалами курса. Сборщик и npm install не нужны. `tools/browser-qa.mjs` проверяет редактор, а `tools/course-browser-qa.mjs` — учебник через DevTools Protocol локального Edge/Chrome, если браузер запущен с портом отладки 9222 (для этих проверок нужен Node.js 22+).

## GitHub Pages

В репозитории используется `.github/workflows/pages.yml`: изменения в ветке `main` запускают тесты, сборку и публикацию папки `dist` на GitHub Pages. Перед первым запуском выберите **Settings → Pages → Source: GitHub Actions**. Секреты и установка npm-пакетов не нужны.

Пути к изображениям, стилям и игровому Worker относительные, поэтому редактор работает и по адресу проекта с префиксом `/NIS-GameCenter/`. Автосохранение существует только в браузере ученика; проекты можно скачивать в JSON. Методичка учителя не включена в публичный сайт.

Для проверки размещения в подпапке у браузерных проверок можно задать `QA_BASE_URL`, например `http://127.0.0.1:5174/NIS-GameCenter/`.

## Ограничения прототипа

Учебная физика дискретная: нет суставов, расчёта вращающего момента при ударах и непрерывного обнаружения столкновений. Быстрые тела могут пролетать через тонкие препятствия. Вращение можно задавать через Transform или `angularVelocity`, но удары не вызывают вращение. Окружность при неравномерном масштабе берёт наибольшую ось.

Один Collider и один Script на объект; нет иерархии родителей, тайлмапов, анимационного редактора, аудио, облачного хранения, совместной работы или экспорта самостоятельной игры. `update` и `fixedUpdate` в этой версии идут с одним шагом 1/60 с.

Worker защищает отзывчивость редактора от бесконечных циклов, но не служит полноценной изоляцией недоверенного кода. Запускайте собственные или доверенные скрипты. Автосохранение существует только в конкретном браузере: скачивайте JSON для резервной копии. Изображение ограничено 4 МБ; проект — 18 МБ, 300 объектов и 100 ресурсов.

## Структура

- `src/model.js` — формат проекта, проверка импорта, пример, история.
- `src/engine/physics.js` — обнаружение и разрешение столкновений.
- `src/engine/runtime.js` — жизненный цикл скриптов и игровой API.
- `src/engine/worker.js` — игровой поток.
- `src/render.js` — Canvas-отрисовка и взаимодействие со сценой.
- `src/main.js`, `src/style.css` — интерфейс редактора.
- `src/course.js` — содержание десяти уроков.
- `src/learning.js`, `src/learning.css` — учебник, скачивание и печать материалов.
- `src/lessons.js` — справка по игровому API и экспорт программы курса.
